# Agente inteligente de citas veterinarias V7.3

Aplicación en Python y Google Colab para reservar, cancelar y reprogramar citas veterinarias. Incluye persistencia en Google Drive, correo SMTP, búsqueda administrativa y comparación de BFS, DFS y A*.

## Ejecución
1. Abra `notebooks/Agente_Citas_Veterinarias_V7_3.ipynb` en Google Colab.
2. Configure los secretos `SMTP_USER` y `SMTP_APP_PASSWORD`.
3. Ejecute todas las celdas y autorice Google Drive.

## Estructura
- `src/search_algorithms.py`: implementación documentada de BFS, DFS y A*.
- `notebooks/`: aplicación completa.
- `tests/`: prueba mínima reproducible.
- `benchmark.csv`: benchmark controlado de los tres algoritmos.
- `docs/`: informe PDF.
